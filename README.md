# XOR Problem Solver Using a Feedforward Neural Network
Mini project, CSE, SCETW Hyderabad.

Solves XOR with a 2-2-1 feedforward network trained by backpropagation,
implemented from scratch in NumPy, with a Keras cross-check.

## Run
pip install -r requirements.txt
python xor_nn.py

## Output
Predictions ≈ [0.019, 0.984, 0.984, 0.017] (classes 0 1 1 0).
Plots saved: perceptron_fail, loss_curve, decision_boundary,
activation_comparison, lr_comparison.
